Features

          
专为国内备案域名与自托管博客打造的无服务器统计服务

        


        

          

            
⚡

            
国内边缘加速

            
托管于腾讯云 EdgeOne 国内边缘节点，彻底告别海外节点晚高峰抽风与 502 错误。

          

          

            
🔒

            
Blob 强一致存储

            
启用 consistency: "strong" 强一致读写，跨运营商（联通/电信）切换绝不丢数。

          

          

            
📡

            
POST 精准上报

            
使用 POST 请求传递当前 URL，克服传统 Referrer 在移动端与 Safari 下的丢失问题。

          

          

            
🛡️

            
白名单与防刷

            
支持 ALLOWED_DOMAINS 域名白名单校验与常见爬虫 User-Agent 只读过滤。

          

          

            
🔄

            
双协议无缝兼容

            
同时兼容 vercount_value_* 与 busuanzi_value_* 标签及 /api/v2/log、/api/v1/log。

          

          

            
🗂️

            
零外部数据库

            
无需额外维护 Redis 或 PostgreSQL，单项目全托管在 EdgeOne，几乎零维护成本。

          

          

            
👥

            
64 桶 UV 去重

            
基于 IP + UA 的 SHA-256 短哈希分桶去重，兼顾精度并极大节省 Blob 写入配额。

          

          

            
🛠️

            
后台管理与迁移

            
内置单管理员后台，支持可视化修改 PV/UV 基数与 JSON 一键导入导出备份。
